# OpenCode 简体中文菜单

将 OpenCode Desktop 的 Windows 应用菜单翻译为简体中文。

## 安装

1. 在 OpenCode 命令面板中运行 `Open MOD folder`。
2. 在打开的目录中执行：

   ```sh
   git clone https://github.com/UR-xiaoyang/opencode-zh-cn-menu.git
   ```

3. 回到 OpenCode，运行 `Refresh MODs`，然后在设置中启用 `OpenCode 简体中文菜单`。

## 兼容性

- 需要支持 MOD Beta 和 `ui.host` 的 OpenCode Desktop。
- 仅支持 Windows。macOS 使用原生应用菜单，无法由渲染器 MOD 修改。

## 权限

此 MOD 使用 `ui.host`，以便在应用菜单渲染后替换其中的文字。
